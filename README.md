# Лабораторная работа 1. Скрипт сборки

Скрипт `build.sh` собирает файл на C, C++ или TeX и кладёт готовый результат в каталог, откуда запущен скрипт.

## Что делает скрипт

1. Находит в файле комментарий `Output:`.
2. Создаёт временный каталог через `mktemp`.
3. Собирает файл в этом каталоге.
4. Копирует результат в каталог, откуда запущен скрипт.
5. Удаляет временный каталог при любом исходе, даже при `Ctrl+C`.

При ошибке скрипт выводит сообщение и возвращает код ошибки (например, 2 — файл не найден, 7 — ошибка компиляции).
